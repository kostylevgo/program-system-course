# Фильтрация кандидатов CRM

## Канонические имена

| Исходные обозначения | Каноническое понятие | Решение |
| --- | --- | --- |
| Карточка, карточка клиента, ClientCard | ClientCard | Один кандидат. |
| Заявка, поданная заявка, Note | Note | Один кандидат. |
| Сделка, проведённая сделка, Deal | Deal | Один кандидат; процесс проведения рассматривается отдельно. |
| Менеджер, менеджер по продажам | SalesManager | Один кандидат и одноимённая роль актора. |
| Руководитель, руководитель отдела | DepartmentHead | Один кандидат и роль актора. |
| Клиент, клиенты | Client | Один кандидат и роль актора. Не синоним карточки. |
| Отчёт, отчет | Report | Один кандидат. |
| Реквизиты, реквизиты клиента | Requisites | Одно понятие данных. |
| Дата и время | DateTime | Составное стандартное значение заявки. |
| Сообщение, текст сообщения | MessageText | Содержание заявки. |
| Ответ, текст ответа | ReplyText | Необязательное содержание ответа. |
| Отдел | Department | Самостоятельность ещё не подтверждена. |

Клиент и карточка не объявляются синонимами. В выбранной модели сведения о клиенте сосредоточены в ClientCard, а роль клиента остаётся на диаграмме вариантов использования.

## Отложенные процессы

| Процесс | Требования | Дальнейшее рассмотрение |
| --- | --- | --- |
| Управление карточками, ManageClients | R1, R5 | Создание ClientCard и updateRequisites; детализация P5. |
| Обработка заявки | R2, R6, R8–R9 | ClientCard.addNote и Note.setReply; детализация P5. |
| Проведение сделки | R3, R6–R7 | ClientCard.recordDeal; внутренний процесс сделки не определён. |
| Подготовка отчёта | R4–R5 | Межобъектный процесс ReportService.prepareReport; выбор P4. |
| Назначение карточек и руководителя | R10–R11 | SalesManager.assignCard и assignHead. Самостоятельный актор назначения не указан. |

После объединения синонимов остаются кандидаты ClientCard, Note, Deal, SalesManager, DepartmentHead, Client, Report, Requisites, DateTime, MessageText, ReplyText и Department. Они проверены в 04-criteria.md, включая кандидатов на простые значения.

ReportService выведен из отложенного процесса «подготовка отчёта» на этапе распределения действий. Он также проходит проверку этапов 3–5; это не дополнительная сущность, якобы прямо названная в исходном тексте.

Из дальнейших проверок исключены система целиком, название CRM, общее понятие функции, работа и местоимения. Основания приведены в 01-nouns.md.
