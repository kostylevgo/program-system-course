# 1. Существительные и именные словосочетания

Слова приведены к начальной форме. Подходящий термин — только кандидат, а не автоматически класс.

| Термин | Фрагмент и источник | Категория | Решение |
| --- | --- | --- | --- |
| Больной | «Больной посещает» — R1 | Роль; субстантивированное прилагательное | Кандидат: пациент |
| Посетитель | «для посетителей» — R2 | Роль | Кандидат; проверить синонимию с больным |
| Доктор | «посещает доктора» — R1 | Роль | Кандидат: врач |
| Рецепт | «получить рецепт» — R1 | Вещь, документ | Кандидат |
| Лекарство | «на лекарства» — R1, «приема лекарств» — R2 | Родовое существительное: отдельный препарат | Кандидат; множественное число не делает слово собирательным |
| Болезнь | «для своей болезни» — R1 | Вид состояния пациента | Неоднозначный кандидат: именуемая болезнь; абстрактность сама по себе здесь не решает вопрос |
| Программа | «для программы-ежедневника» — R2 | Программный продукт целиком | Не класс предметной области: граница системы |
| Ежедневник | «программы-ежедневника» — R2 | Вещь: индивидуальный журнал | Кандидат: совокупность записей пациента |
| Приём лекарств | «ежедневника приема лекарств» — R2 | Процесс | Отложить до анализа действий; разовое событие рассмотреть отдельно |
| Метод Аббота | «Применив метод Аббота» — R3 | Методика и собственное имя автора | Исключить из предметной области |
| Класс | «выделите классы» — R3 | Метапонятие моделирования | Исключить из предметной области |
| Модель предметной области | «постройте модель предметной области» — R3 | Результат задания, абстрактное понятие | Исключить из предметной области |
| Свой | «для своей болезни» — R1 | Местоимение, не существительное | Не кандидат; указывает принадлежность болезни пациенту |

## Уточнения из проектных предположений

Эти понятия не выдаются за буквальные слова исходной фразы.

| Термин | Основание | Категория | Решение |
| --- | --- | --- | --- |
| Назначение | R1 «рецепт на лекарства», уточнение A3 | Строка рецепта: лекарство и схема приёма | Кандидат, необходимый для представления нескольких схем |
| ПриёмЛекарства | R2 «приема лекарств», уточнения A4–A5 | Одно плановое событие с отметкой | Кандидат; отличается от процесса приёма вообще |
| Доза, дата, время, статус | A2–A5 | Значения свойств | Передать на этап 5 как атрибуты; не самостоятельные классы |

Названий конкретных экземпляров в условии нет.
