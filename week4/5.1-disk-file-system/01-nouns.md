# Этап 1. Существительные и именные сочетания

| Термин | Фрагмент и источник | Категория | Решение |
| --- | --- | --- | --- |
| Диск | «Диск состоит…», R1; «На диске…», R2 | Вещь, физический носитель | Кандидат Disk. |
| Кластер | «пронумерованных кластеров», R1; «в одном кластере диска», R3; «в нескольких кластерах», R4 | Вещь, адресуемая часть диска | Кандидат Cluster; не процесс и не собирательное понятие. |
| Папка | «именованные папки», «вложены папки», R2; «в папке», R3 | Вещь, логический контейнер | Кандидат Folder. Вложенная папка — роль того же класса. |
| Файл | «именованные файлы», R2; «данные файлов», R4 | Вещь, логический объект хранения | Кандидат File. |
| Список файлов и папок | «Список файлов и папок в папке», R3 | Собирательное понятие | Не отдельный класс: коллекция непосредственных связей папки с содержимым. Связь с кластером хранения сохраняется. |
| Данные файла | «данные файлов», R4 | Собирательное понятие, информационное содержимое | Не отдельный класс: содержимое кластеров и результат чтения файла. Формат данных не задан. |
| Имя | Подразумевается прилагательным «именованные», R2 | Значение, характеристика объекта | Атрибут name у Folder и File; это не название конкретного экземпляра. |
| Номер | Подразумевается прилагательным «пронумерованных», R1 | Значение, характеристика объекта | Атрибут number у Cluster. Не вводится класс Number. |

Конкретных названий экземпляров и существительных, обозначающих роли людей, в тексте нет. «В которые» — местоименная отсылка к папкам, нового понятия не образует. «Данные» и «список» отклонены как самостоятельные классы, но не исключены из модели.
