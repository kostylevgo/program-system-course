# Задача 5.1: файловая система диска

Исходный текст:

> 5.1. Диск состоит из пронумерованных кластеров. На диске есть именованные папки,
> в которые вложены папки или именованные файлы. Список файлов и папок в папке хранится
> в одном кластере диска, данные файлов хранятся в нескольких кластерах.

## Требования

| Код | Фрагмент | Требование модели |
| --- | --- | --- |
| R1 | «Диск состоит из пронумерованных кластеров» | У диска есть кластеры; каждый имеет номер внутри своего диска. |
| R2 | «На диске есть именованные папки, в которые вложены папки или именованные файлы» | Папки размещены на диске, имеют имена и могут содержать папки и файлы; файлы имеют имена. «Или» перечисляет виды содержимого, а не запрещает их совместное присутствие. |
| R3 | «Список файлов и папок в папке хранится в одном кластере диска» | Для списка непосредственного содержимого каждой папки используется ровно один кластер. |
| R4 | «Данные файлов хранятся в нескольких кластерах» | Для данных каждого файла используется несколько кластеров. Буквальное прочтение: 2..*. |

## Проектные предположения

Эти решения дополняют неполное описание и не выдаются за требования задачи.

| Код | Решение | Для чего нужно |
| --- | --- | --- |
| A1 | Иерархия папок — лес: у папки не более одного непосредственного родителя, циклов нет; у файла ровно одна папка. Ссылки и несколько имён одного объекта не моделируются. | Определить кратности вложенности. Несколько папок верхнего уровня допустимы; отдельный класс корня не вводится. |
| A2 | Папка может быть пустой; диск может временно не содержать папок. Диск имеет хотя бы один кластер. | Задать нижние границы коллекций. Пустой диск — обобщение фразы «есть папки». Файлы, занимающие ноль или один кластер, не включены в выбранную трактовку R4. Размер логических данных файла условием не задан. |
| A3 | Кластер используется не более чем одним файлом либо одним списком папки; неиспользуемые кластеры допустимы. | Задать обратные кратности 0..1 и запрет совместного использования. Эксклюзивность в исходном тексте не задана. |
| A4 | Для проверки модели рассматривается внешний «Наблюдатель модели» и цели чтения: найти кластер, просмотреть папку, прочитать файл. Это проверочные use cases, а не заданные пользователем функциональные требования. | Выполнить этап 7 скилла без выдумывания операций изменения. |
| A5 | При проверке чтения содержимое кластера представлено последовательностью байтов; кластеры данных файла упорядочены и не повторяются. Учитывается логически значимая полезная нагрузка; формат, заполнение и служебные заголовки не определяются. | Восстановить данные файла без добавления неописанных размера кластера, размера файла и алгоритма кодирования. |
| A6 | Диск, папка и файл имеют объектную идентичность, независимую от значений их полей. Кластер идентифицируется парой (диск, номер). | Обосновать тип Entity. Служебные идентификаторы в предметную модель не добавляются. |

Атрибуты имени и номера не становятся отдельными классами. Уникальность номера внутри диска — интерпретация нумерации R1; начальный номер и непрерывность не заданы. Уникальность имён, фиксированная ёмкость кластеров и операции создания/удаления также не заданы.

Выбранная модель замкнута принятыми предположениями. Для применения к конкретной файловой системе требуется уточнить A1–A3, допустимость файлов в 0 или 1 кластере, правила имён и физический формат хранения. Для решения учебной задачи эти уточнения не блокируют результат.
