# Этап 2. Фильтрация

| Каноническое имя | Исходные формы и сочетания | Решение |
| --- | --- | --- |
| Disk / Диск | диск, диске, диска | Один кандидат, R1–R3. |
| Cluster / Кластер | кластеров, кластере, кластерах; кластер списка; кластер данных | Один кандидат, R1, R3, R4. Последние два сочетания обозначают роли, а не доказанные подтипы. |
| Folder / Папка | папки, папок, папке; вложенная папка | Один кандидат, R2, R3. Родительская и вложенная папки — роли на рекурсивной связи. |
| File / Файл | файлы, файлов | Один кандидат, R2, R4. |

Содержательных синонимов, требующих слияния разных терминов, нет; объединены словоформы и ролевые сочетания.

Отложенных существительных-процессов нет. «Хранится», «вложены», «состоит» будут рассмотрены как предикаты на этапе 3; они не являются существительными-процессами.

Оставшиеся кандидаты: Disk, Cluster, Folder, File. Для этапа 5 сохранены: список содержимого, данные, имя, номер. Новый общий класс «Элемент файловой системы» не вводится: исходный текст не требует полиморфного поведения; общность имени сама по себе не требует наследования.
