# 2. Фильтрация

| Каноническое имя | Исходные формы/синонимы | Решение |
|---|---|---|
| Фактор | фактор, факторы, фактор качества | Оставить. |
| Критерий | критерий, критерии, критерий качества | Оставить. |
| Метрика | метрика, метрики | Оставить; общая метрика не копируется для каждого критерия (R4). |
| ЭтапРазработки | этап разработки, этап, фаза | Объединить. Анализ и Реализация — экземпляры. |
| ПрограммноеСредство | программное средство, ПС | Один предварительный кандидат. |
| Стандарт | межгосударственный стандарт | Один предварительный кандидат; ГОСТ 28195—89 — имя экземпляра. |
| ОписаниеФактораНаЭтапе | описание/набор критериев фактора на этапе | Оставить как рефицированную связь R2, R6. Не синоним самого фактора. |
| НастройкаКритерияНаЭтапе | набор метрик критерия на этапе | Оставить как рефицированную связь R3, R6. Не синоним метрики и не замер. |

## Отложенные процессы

| Процесс | Дальнейшая судьба |
|---|---|
| Оценка качества | В тексте нет процедуры вычисления оценки; отдельный Service не выводится. |
| Разработка программного средства | Даёт контекст ЭтапРазработки; жизненный цикл разработки вне задачи. |
| Описание фактора критериями | Состояние хранит ОписаниеФактораНаЭтапе; составление/замена набора — его операции и describeFactor этапа (D1). |
| Измерение критерия | Исходное «измеряется» означает здесь связь с определениями метрик. Результаты измерений и measure() не добавляются. Настройка набора — configureCriterion/setMetrics (D1). |
| Использование метрики | Ассоциация НастройкаКритерияНаЭтапе–Метрика; не отдельный Service. |
| Восстановление, управление, функционирование, обработка | В составе названий метрик 1–5; остаются текстом name, а не операциями нашей системы. |

## Оставшиеся кандидаты

Фактор, Критерий, Метрика, ЭтапРазработки, ПрограммноеСредство, Стандарт, ОписаниеФактораНаЭтапе, НастройкаКритерияНаЭтапе.

Качество, набор, названия экземпляров и метаязык задания не восстанавливаются как классы. Их судьба прослеживается в этапе 5.
