# 5. Атрибуты, операции, связи

## Атрибуты и операции

У Фактор, Критерий, Метрика и ЭтапРазработки имеется публично читаемый name: String {readOnly}. Название задаётся при создании. Дополнительные идентификаторы, веса, формулы, шкалы и числовые значения не выдумываются.

Остальное состояние — именованные концы ассоциаций в следующей таблице; их не нужно дублировать как независимые поля классов.

| Класс | Операция | Контракт |
|---|---|---|
| ЭтапРазработки | configureCriterion(criterion: Критерий, metrics: Set<Метрика>): НастройкаКритерияНаЭтапе | Создаёт настройку для пары (criterion, this) либо заменяет метрики существующей через setMetrics. Проверяет размер ≥ 2. Возвращает единственный объект пары. |
| ЭтапРазработки | describeFactor(factor: Фактор, settings: Set<НастройкаКритерияНаЭтапе>): ОписаниеФактораНаЭтапе | Создаёт описание пары (factor, this) либо заменяет его набор через setCriteria. Требует непустой набор настроек этого этапа. |
| ЭтапРазработки | factors(): Set<ОписаниеФактораНаЭтапе> | Возвращает доступные описания факторов данного этапа. |
| ОписаниеФактораНаЭтапе | setCriteria(settings: Set<НастройкаКритерияНаЭтапе>): void | Атомарно заменяет criterionSettings; проверяет непустоту и совпадение этапа. Не меняет factor или stage. |
| ОписаниеФактораНаЭтапе | criteria(): Set<Критерий> | Возвращает критерии включённых настроек. |
| НастройкаКритерияНаЭтапе | setMetrics(metrics: Set<Метрика>): void | Атомарно заменяет metrics; не менее двух различных метрик. Не меняет criterion или stage. |
| НастройкаКритерияНаЭтапе | metrics(): Set<Метрика> | Возвращает набор определений метрик для чтения, а не изменяемую извне коллекцию. |

Возвращаемые коллекции читаются без обхода проверок. Отказ проверки оставляет прежнее состояние. Создание через операции этапа публикует только полностью заполненный объект. Операции удаления определений или этапов не требуются условием. Все эти контракты относятся к D1, D5.

## Связи, роли и кратности

Кратность у конца B — число B для одного A. Все шесть отношений — обычные двусторонне читаемые **ассоциации**, без композиции, агрегации или наследования.

| A | Роль A; кратность у A | Имя связи | B | Роль B; кратность у B | Основание |
|---|---|---|---|---|---|
| Фактор | factor; 1 | описывается | ОписаниеФактораНаЭтапе | descriptions; 0..* | Каждое описание относится к одному фактору; фактор имеет описания по этапам (R2). |
| ЭтапРазработки | stage; 1 | задаёт контекст описания | ОписаниеФактораНаЭтапе | factorDescriptions; 0..* | У каждого описания один этап; этап описывает множество факторов (R2, R6). |
| Критерий | criterion; 1 | настраивается | НастройкаКритерияНаЭтапе | settings; 0..* | У настройки один критерий; наборы критерия могут отличаться по этапам (R3). |
| ЭтапРазработки | stage; 1 | задаёт контекст настройки | НастройкаКритерияНаЭтапе | criterionSettings; 0..* | У настройки один этап (R3, R6). |
| ОписаниеФактораНаЭтапе | factorDescriptions; 0..* | включает | НастройкаКритерияНаЭтапе | criterionSettings; 1..* | У описания непустой набор настроек; настройка может участвовать у нескольких факторов того же этапа (D2–D3). |
| НастройкаКритерияНаЭтапе | usages; 0..* | использует | Метрика | metrics; 2..* | Настройка использует несколько метрик; метрика доступна разным критериям и этапам (R3–R4). |

Кратности приняты явно: нижние границы 1 и 2 объяснены в D2; 0 для обратных связей — разрешённые незадействованные элементы при составлении схемы (D6). Иных неизвестных кратностей в выбранной модели не осталось. Исходный текст сам по себе не определяет полноту черновика и жизненный цикл объектов.

## Ограничения сверх кратностей

- C1. ОписаниеФактораНаЭтапе уникально по (factor, stage).
- C2. НастройкаКритерияНаЭтапе уникальна по (criterion, stage).
- C3. Для каждой настройки в описании: description.stage = setting.stage.
- C4. Все многозначные роли являются множествами; повторная ссылка не увеличивает размер. В одном описании не бывает двух настроек одного критерия благодаря C2–C3.
- C5. Пары ключевых ссылок неизменяемы. Обновление через describeFactor/configureCriterion использует существующий объект, поэтому не создаёт дубликатов C1–C2.
- C6. Готовая схема содержит описание каждой пары из декартова произведения рассматриваемых факторов и этапов (R2, D6). Обратные 0..* допускают промежуточное состояние, но не отменяют это условие полноты.
- C7. Общая метрика сохраняет идентичность при повторном использовании (D4). Смена набора на одном этапе не меняет набор другого этапа. При общей настройке одного критерия внутри одного этапа её изменение видно всем ссылающимся факторам (D3).

Прямая связь Фактор–Критерий без этапа теряет R2/R6, а прямая связь Критерий–Метрика без этапа теряет R3/R6. Дополнительная связь описания непосредственно с критерием избыточна: он достижим через настройку. Оснований для композиции нет — удаления и зависимые жизненные циклы условием не определены.
