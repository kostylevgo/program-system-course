# Этап 1. Существительные и именные сочетания

Словоформы приведены к начальной форме. Пригодность термина на этом этапе означает только включение в кандидаты; окончательное решение принимается по критериям этапа 4.

| Термин | Фрагмент и требование | Категория | Решение |
| --- | --- | --- | --- |
| Больной | «Больной посещает», «больными»; R1, R3 | Субстантивированное прилагательное, роль человека | Подходит; каноническое имя Пациент. |
| Доктор | «посещает доктора», «посещений … докторов»; R1, R3 | Роль человека | Подходит. |
| Рецепт | «получить рецепт»; R2 | Документ, отдельный предметный объект | Подходит. |
| Лекарство | «на лекарства»; R2 | Родовое существительное; множественное число обозначает отдельные препараты | Подходит как кандидат; это не собирательное существительное. |
| Болезнь | «для своей болезни»; R2 | Вид состояния пациента | Предварительно подходит как предметное понятие. Текст пока требует только указать, для чего выписаны лекарства. |
| Посещение | «учета посещений»; R3 | Процесс; также может означать отдельный произошедший факт | Отложить процесс, затем проверить самостоятельность записи о факте. |
| Поликлиника | «для поликлиники»; R3 | Организация, родовое существительное | Подходит как кандидат; проверить, нужен ли объект внутри модели. |
| Учёт | «системы учета»; R3 | Абстрактное существительное, процесс | Не считать вещью; сохранить как ответственность системы. |
| Система учёта | «системы учета посещений»; R3 | Название проектируемой системы | Граница моделирования, а не автоматически отдельный класс. |
| Метод Аббота | «Применив метод Аббота»; R4 | Название метода анализа | Не относится к предметной области. Имя Аббота не обозначает объект поликлиники. |
| Класс | «выделите классы»; R4 | Термин моделирования | Не относится к предметной области. |
| Модель предметной области | «постройте модель предметной области»; R4 | Результат учебного задания | Не относится к предметной области поликлиники. |
| Свой | «для своей болезни»; R2 | Притяжательное местоимение, не существительное | Не класс; указывает, что болезнь относится к пациенту данного посещения. |

«5.2» и «а» — номера задания, предметных объектов не обозначают. Названий конкретных пациентов, докторов, болезней или лекарств в тексте нет.
