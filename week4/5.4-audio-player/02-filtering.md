# Этап 2. Нормализация и фильтрация

| Каноническое имя | Русское имя | Объединённые термины | Основание |
| --- | --- | --- | --- |
| `AudioPlayer` | Аудиоплеер | Аудиоплеер, плеер | R1/R4. |
| `PluginManager` | Менеджер модулей | Менеджер подключаемых модулей, менеджер модулей | R1/R10. |
| `UserInterface` | Пользовательский интерфейс | Пользовательский интерфейс, UI | R1/R2/R7. |
| `PlayerController` | Управляющий компонент | Управляющий компонент, контроллер | R1/R3. |
| `MediaLibrary` | Библиотека мультимедиа | Библиотека мультимедиа | R1/A2: программная библиотека. |
| `Plugin` | Установленный модуль | Подключаемый, установленный, загружаемый модуль | R4/R6/R10: состояния одного объекта. |
| `Command` | Команда | Команда, конкретизированный пользовательский запрос | R2/R7. |
| `ConnectionManager` | Менеджер соединений | Менеджер соединений | R8/R10. |
| `PluginServer` | Сервер модулей | Сервер | R9/R10. |
| `ModuleCatalog` | База доступных модулей | База модулей, каталог доступных версий | R9. |
| `PluginDescriptor` | Описание доступной версии | Доступный модуль, сведения о новой версии | R9/R10: запись с идентификатором и версией, не исполняемый объект. |
| `User` | Пользователь | Пользователь | Кандидат для проверки; внешняя роль. |
| `PlayerComponent` | Компонент плеера | Компонент | Кандидат на обобщение; общего протокола не задано. |
| `Connection` | Соединение | Соединение | Кандидат на отдельный ADT канала. |

После нормализации проверяются все 14 кандидатов. Итоговое принятие выполняется
на этапе 4, а не скрыто на этом этапе. Серверный `PluginDescriptor` не объединяется
с `Plugin`: доступная версия может вообще не быть установлена у клиента.

| Отложенный процесс / понятие | Дальнейшее назначение |
| --- | --- |
| Загрузка | `PluginManager.load` → `Plugin.load`; изменение состояния модуля. |
| Включение / выключение | `enable` / `disable` у менеджера и модуля. |
| Обработка ввода | `UserInterface.submit`; преобразование действия пользователя в `Command`. |
| Асинхронная обработка | `enqueue`, `processNext`, `Future`, очередь и таблица ожидаемых ответов. |
| Основная функциональность | `PlayerController.play/pause/stop`, A9. |
| Подключение к серверу | `ConnectionManager.connect/disconnect`. |
| Проверка обновлений | `PluginManager.checkUpdates`, сетевой запрос, сравнение в каталоге. |
| Обновление как найденная версия | Значение `PluginDescriptor`, без операции установки. |
| Пользовательский ввод | Поля команды; необработанные события ОС не моделируются. |
| Система | Граница диаграммы вариантов использования. |

Классы для «потока», «асинхронности», «загрузки» и «функциональности» не создаются:
это механизмы или процессы, а не самостоятельные объекты рассматриваемой модели.
